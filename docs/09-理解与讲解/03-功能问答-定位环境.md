| 维度          | 定位                                                                     |

### Q0.4 数据库用了存储过程/触发器吗？事务和锁呢？


| 维度           | 定位                                                                                        |
| ------------ | ----------------------------------------------------------------------------------------- |
| **结论**       | **无**存储过程、存储函数、触发器、MySQL EVENT；业务在 `AppService.java`                                      |
| **MySQL 用了** | 16 表 + 外键/唯一索引 + 视图 `v_room_daily_usage` → `docs/06-部署配置/schema.sql`                      |
| **事务**       | Spring `@Transactional`（预约/取消/签到/签退等）→ `AppService` 搜索 `@Transactional`                   |
| **并发**       | `reservation_slot.uk_seat_slot` + `DuplicateKeyException` → 409，**无** `SELECT FOR UPDATE` |
| **定时**       | `ScheduledTaskService` 每分钟四条，**非** DB 触发器                                                 |
| **详解**       | [01·F7.1](01-项目理解指南.md#f7-1) · [02·答辩](02-答辩讲解手册.md#f7-1)                                 |
