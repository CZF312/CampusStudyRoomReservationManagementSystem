# 目录结构说明

> 本文说明项目根目录下**每个文件夹/关键文件**的职责。  
> 原则：**代码在 `src/` 与 `frontend/`，文档在 `docs/`，运行时数据在 `uploads/`。**

---

## 根目录一览

```
CampusStudyRoomReservationManagementSystem/
├── docs/                    # 📚 全部文档（不参与编译）
├── scripts/                 # 🔧 自动化脚本（导入/验收/构建/共用库）
├── frontend/                # 🖥️ Vue 3 前端源码
├── src/                     # ☕ Spring Boot 后端源码 + 打包后的静态页
├── uploads/                 # 📎 运行时上传文件（git 忽略，本地自动生成）
├── target/                  # 🔧 Maven 编译产物（git 忽略）
├── .mvn/                    # Maven Wrapper 配置
├── pom.xml                  # 后端依赖与构建配置
├── mvnw / mvnw.cmd          # 无需全局安装 Maven 即可构建
├── README.md                # 项目入口：启动与验收
├── INSTALL.md               # 安装部署指南
├── DIRECTORY.md             # 目录说明
├── PROJECT_STRUCTURE.md     # 完整目录索引
├── HELP.md                  # 帮助文档
├── QUICKSTART.txt           # 三步快速开始
└── start.bat / start.cmd / start.vbs  # 一键启动入口
```

---

## `docs/` — 文档中心


| 子目录             | 内容                  |
| --------------- | ------------------- |
| `00-部署与验收/`     | 部署与验收索引             |
| `01-使用指南/`      | 面向新手的讲解、操作指南        |
| `02-架构说明/`      | 架构图、目录规范            |
| `03-开发维护/`      | 开发原则、问题记录、UI 对齐     |
| `04-版本记录/`      | 版本基线、更新说明、更新日志      |
| `05-需求与设计/`     | 需求/概要/详细设计（课程正式文档）  |
| `06-部署配置/`      | SQL 文件、Docker Compose、数据库范式说明 |
| `07-原型资源/`      | HTML 原型（参考用，非运行时代码） |
| `08-课设交付/`      | 课程设计报告 Word、全量验收清单  |


**规范**：新增说明类 `.md` 一律放入 `docs/` 对应子目录，**不要在根目录堆文档**。

## `frontend/` — 前端工程

```
frontend/
├── src/
│   ├── App.vue          # 主应用（学生端 + 管理端全部页面）
│   ├── main.js          # Vue 入口
│   ├── qr.js            # 二维码 SVG 生成
│   └── styles.css       # 全局样式
├── index.html           # HTML 壳
├── vite.config.js       # 开发服务器 + /api 代理到 8080
├── package.json         # npm 依赖与脚本
└── package-lock.json
```


| 命令              | 作用                                  |
| --------------- | ------------------------------------- |
| `npm install`   | 安装依赖（首次必做）                          |
| `npm run dev`   | 开发模式 → http://localhost:5173          |
| `npm run build` | 打包到 `../src/main/resources/static`    |


---

## `src/` — 后端工程

```
src/main/java/com/scau/campusstudyroomreservationmanagementsystem/
├── CampusStudyRoomReservationManagementSystemApplication.java  # 启动类
├── controller/          # REST 接口（对外 URL）
│   ├── AppController.java
│   └── UploadController.java
├── service/             # 业务逻辑
│   ├── AppService.java
│   ├── DatabaseInitializer.java
│   └── ScheduledTaskService.java
├── config/              # 安全、JWT、静态资源、上传存储
│   ├── SecurityConfig.java
│   ├── JwtAuthFilter.java
│   ├── JwtService.java
│   ├── UploadStorage.java
│   └── WebConfig.java
└── support/             # 统一响应、异常、当前用户、SQL 片段
    ├── ApiResponse.java
    ├── BusinessException.java
    ├── CurrentUser.java
    ├── GlobalExceptionHandler.java
    └── SqlFragments.java

src/main/resources/
├── application.properties              # 端口、数据库、JWT、上传目录
├── application-local.properties.example   # 本机配置示例
├── application-shared.properties.example  # 共用库配置示例
└── static/                             # 前端 build 产物（8080 直接访问）

src/test/java/             # 测试（H2 内存库）
```

**规范**：

- 新接口 → `controller/`
- 新业务流程 → `service/`（或新建 XxxService）
- 不改 `support/` 除非调整统一响应/异常格式

---

## `uploads/` — 用户上传文件

```
uploads/
├── material/            # 学生注册身份材料 PDF
├── layout/              # 自习室座位分布图
└── common/              # 其他上传文件
```

通过 URL `/uploads/material/xxx.pdf`、`/uploads/layout/xxx.jpg` 访问。目录在首次上传或启动后自动创建。

---

## 不应提交到 Git 的内容

已在 `.gitignore` 中配置：

- `target/` — Maven 编译输出
- `frontend/node_modules/` — 前端依赖
- `uploads/` — 本地上传文件
- `src/main/resources/application-local.properties` — 本机密码
- `src/main/resources/application-shared.properties` — 共用库密码
- `.idea/`、`.vscode/` — IDE 配置
