# 09 — 全量交付与一键验收

> **目标**：将当前环境中的「代码 + 数据库全量数据 + 上传图片 + 已构建前端」一次性提交到 Git；接收方下载 ZIP 后**双击 `start.bat`**，即可看到与提交时相同的界面和数据。

---

## 一、需要提交到 Git 的内容

### 1. 必交（验收核心）

| 类别 | 路径 | 说明 |
| --- | --- | --- |
| **数据库全量快照** | `docs/06-部署配置/database-full.sql` | 结构 + 全部业务数据 |
| 数据库结构 | `docs/06-部署配置/schema.sql` | 仅表结构 |
| 数据库数据 | `docs/06-部署配置/data.sql` | 仅 INSERT 数据 |
| 建库脚本 | `docs/06-部署配置/init-local-database.sql` | 本地建库（一键脚本使用） |
| **一键启动** | `start.bat`、`scripts/start-system.ps1` | 清空导入 + 验收 + 启动 |
| 环境脚本 | `scripts/setup-after-clone.ps1` | 导入与配置 |
| 交付清单 | `docs/06-部署配置/delivery-manifest.json` | 导出时间与资源统计 |

### 2. 强烈建议一并提交

| 类别 | 路径 | 说明 |
| --- | --- | --- |
| **已构建前端** | `src/main/resources/static/` | 无需 Node 即可访问 8080 |
| **上传文件** | `uploads/material/`、`uploads/layout/` | 注册材料、平面图 |
| 项目源码 | `src/`、`frontend/`、`pom.xml` 等 | 正常代码提交 |

### 3. 不要提交

| 路径 | 原因 |
| --- | --- |
| `application-local.properties` | 含本机 MySQL 密码 |
| `target/`、`frontend/node_modules/` | 可重新生成 |

## 二、提交者操作步骤

```powershell
cd <项目根目录>

# 1. 确保 MySQL 已启动，库内为要交付的数据
# 2. 导出 SQL + 检查前端 + 生成交付清单
.\scripts\prepare-full-delivery.ps1

# 3. 按脚本提示 git add / commit / push
git add docs/06-部署配置/schema.sql docs/06-部署配置/data.sql docs/06-部署配置/database-full.sql
git add docs/06-部署配置/delivery-manifest.json
git add docs/01-使用指南/09-全量交付与一键验收.md
git add start.bat scripts/start-system.ps1 scripts/setup-after-clone.ps1
git add uploads/material uploads/layout
git add src/main/resources/static
git commit -m "chore: 全量交付快照（数据库+上传文件+前端）"
git push
```

## 三、接收方操作步骤 — 下载 ZIP 后双击

### 环境要求

| 组件 | 版本 |
| --- | --- |
| JDK | 21+ |
| MySQL | 8.x（服务已启动） |
| Git | **不需要**（Download ZIP 即可） |

**不需要** Node.js（前端已打包在 `static/`）。

### 推荐流程

1. GitHub → **Code** → **Download ZIP**
2. 解压，进入含 `pom.xml` 的文件夹
3. 阅读 `QUICKSTART.txt`，双击 **`start.bat`**
4. 按提示输入本机 MySQL root 密码

`start.bat` 将自动：

1. 检测 Java、MySQL 客户端与前端静态资源
2. 写入 `application-local.properties`（仅本机）
3. **DROP** 旧库 `study_room_reservation` 并导入 `database-full.sql`
4. 运行 17 项数据库验收
5. 启动后端（窗口 `CSRRMS-Backend`）并打开 http://localhost:8080

### 可选：命令行

```powershell
.\scripts\setup-after-clone.ps1
# 或仅导入
.\scripts\import-database-local.ps1 -UseFullDump -Password <密码>
```

## 五、常见问题

| 问题 | 处理 |
| --- | --- |
| MySQL Access denied | 输入**本机** root 密码，与提交者无关 |
| 图片 404 | 确认 `uploads/` 已提交且 `app.upload.dir` 正确 |
| 数据不一致 | 提交者需重新执行 `prepare-full-delivery.ps1` 并 push |
| 仅导入不启动 | `.\scripts\import-database-local.ps1 -UseFullDump` |
