# 01 — 提交者必做清单

> **工作目录**：`<项目根目录>`（含 `pom.xml` 的目录）  
> **验收方**：请阅读根目录 [QUICKSTART.txt](../../QUICKSTART.txt) 并双击 [start.bat](../../start.bat)。

---

## 一、本机开发 / 测试

1. 保证 MySQL 已启动。  
2. 配置 `src/main/resources/application-local.properties`（不提交 Git）。  
3. 启动：

```powershell
cd <项目根目录>
.\mvnw.cmd spring-boot:run
```

4. 浏览器打开 http://localhost:8080。

改前端后：

```powershell
.\scripts\build-frontend.ps1
.\mvnw.cmd spring-boot:run
```

---

## 二、全量交付（每次同步数据前）

```powershell
cd <项目根目录>
.\scripts\prepare-full-delivery.ps1
```

自测（推荐）：

```powershell
.\scripts\verify-startup.ps1 -MySqlPassword 你的MySQL密码
```

提交并推送：

```powershell
git add docs/06-部署配置/schema.sql docs/06-部署配置/data.sql docs/06-部署配置/database-full.sql
git add docs/06-部署配置/delivery-manifest.json
git add docs/01-使用指南/09-全量交付与一键验收.md
git add start.bat scripts/start-system.ps1 scripts/setup-after-clone.ps1
git add uploads/material uploads/layout
git add src/main/resources/static
git commit -m "chore: 全量交付快照（数据库+uploads+前端）"
git push
```

通知验收方：**Code → Download ZIP** → 解压 → 双击 **`start.bat`**。
